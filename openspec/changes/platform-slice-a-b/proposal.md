# Platform Slice A and B

## Why
The prototype cannot establish independent gate ownership, restart-safe attempts,
portable installation, or candidate-bound completion. Build a real plugin/runtime
vertical path without weakening the approved quality and security contracts.

## What Changes
- Plugin packaging and selective project integration with reversible installation.
- Versioned technology packs and project manifests.
- Durable isolated jobs, bounded execution, independent gates and review, evidence.
- Disposable Python acceptance feature and external Go extension conformance.

## Impact
New platform APIs only. Existing Eventu behavior and global user configuration are preserved.
