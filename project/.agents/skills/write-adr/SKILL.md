# write-adr

First establish constraints and alternatives with architecture_reviewer and the affected technology engineer. Write Context, Decision, Alternatives rejected, Security/privacy, Migration/rollout, Rollback, Verification and Review date. Mark ADR proposed until explicitly approved. Update decisions/index.md after approval; do not let suggestions silently become policy.
