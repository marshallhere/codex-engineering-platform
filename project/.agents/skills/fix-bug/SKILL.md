# fix-bug

Start by reproducing the observed issue or explaining why reproduction is blocked. Use relevant specialists to map and inspect the failing path; isolate likely hypotheses, gather logs, write a regression test BEFORE or alongside fix, then implement minimal correction. Run test_runner and code_reviewer; use browser_qa for UI. For prior wrong assumptions or a repeated issue, invoke learn-from-feedback. Do not treat a guessed cause as confirmed.
