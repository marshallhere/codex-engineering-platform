# browser-qa

Define test charter, environment, test account and permitted URL. Use browser_qa specialist and Playwright MCP to navigate forms, edge states, validation, keyboard and responsive flows. Save precise repro steps and traces/screenshots when allowed. Convert stable, confirmed issues into Playwright Test specs through test_designer. Run saved browser tests with the normal test runner/CI; do not mistake a transient exploratory run for automated coverage. No production/private accounts.
