# Engineering knowledge hierarchy

1. `AGENTS.md` + `invariants.md`: must-follow documented policy, limited by enforcement of OS sandbox/CI/permissions.
2. `decisions/index.md`: approved architectural choices and references.
3. `lessons/index.md`: previously confirmed failures and prevention/regression tests.
4. Personal `~/.codex/PREFERENCES.md`: user style and priorities, not shared in repos.
5. Native local Codex memories: contextual recall only, not a definitive policy source.
6. Unreviewed `.codex/learning/pending/`: **proposals only** and never injected automatically.

On contradictory evidence, escalate for clarification and propose an ADR revision. Store the minimum durable information; do not save session transcripts, secrets, internal tokens or user data.
